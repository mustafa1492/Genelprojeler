# Dayıbaşı Takip-Kayıt Sistemi

Tarım işçisi ekipleri yöneten dayıbaşılar için telefondan kullanılan, sade bir takip sistemi: ekip, arabalar ve izin kâğıtları, günlük kayıt, çiftçi alacakları.

Aynı çekirdek (`core/`) ileride randevu, saha takip ve esnaf web sitesi ürünlerinde de kullanılacak.

- Başlangıç: `ILK-ADIM.md`
- Proje kuralları (Claude Code okur): `CLAUDE.md`
- Ürün tarifi: `docs/urun.md`
- Modüller ve ortak çekirdek: `docs/moduller.md`
- Tasarım: `docs/tasarim/`
- Yol haritası: `docs/yol-haritasi.md`
- Araştırma: `docs/arastirma.md`
- Diğer fikirler: `docs/fikirler/`
- Veritabanı: `supabase/migrations/0001_core.sql`
